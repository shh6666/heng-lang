# 衡语 IDE 设计文档

用衡语写的 macOS 原生 IDE。图形逻辑全在 `.hng` 里，C 桥接层只做渲染。

## 架构

```
ide.hng           主程序：布局、事件分发、命令执行
commands.hng      命令注册表：名字→说明、按键→命令
highlight.hng     语法高亮：源码 → 标记文本
files.hng         多文件工作区
complete.hng      自动补全
native/hengui.m   AppKit 桥接（约 1400 行 C）
```

**分层原则**：凡是「语言知识」都放在衡语里。
高亮规则、命令表、快捷键绑定、补全候选——改这些不用重编 dylib。

## 命令系统

**核心设计**：按钮、菜单、快捷键三个入口，最终都走 `跑命令(名)` 一个出口。

```
按钮 action ──┐
菜单项     ──┼──→ 处理动作/处理按键 ──→ 跑命令(命令名) ──→ 具体实现
快捷键     ──┘
```

**为什么这么做**：加一个功能只需在 `commands.hng` 注册一行，
三个入口自动都能用，也就不会出现「菜单有但按钮没有」这种不一致。

## 快捷键实现

`HengRoot` 重写 `performKeyEquivalent`，把「修饰键 + 字符」翻译成事件：

```
按下 Cmd+Shift+P  →  推事件 "快捷键|cmd+shift+p"
                  →  衡语查 键表["cmd+shift+p"] = "视图.命令面板"
                  →  跑命令("视图.命令面板")
```

**只拦带 Command/Control/Option 的单字符**——不带修饰键的按键交给正常输入，
多字符说明是输入法组合也不拦。这样不会干扰中英文输入。

## 命令面板

借鉴 VS Code 的 Cmd+Shift+P 与 Sublime 的 Goto Anything。

- 一个无边框 `NSPanel`，圆角、带阴影、悬浮层
- 搜索框实时子串过滤
- ↑↓ 选择，回车执行，Esc 关闭
- 候选格式：`说明    命令名`，选中后由 `解析面板选择()` 取最后一段

文件切换（Cmd+P）复用同一个面板，只是候选换成文件名。

## 语法高亮

**衡语负责分类，C 层负责上色。**

衡语把源码编译成标记文本：
```
\x01 K \x02 如果        K=控制关键字
\x01 R \x02 变量        R=声明字
\x01 T \x02 数          T=类型
\x01 N \x02 42          N=数字
\x01 S \x02 "文本"      S=字符串
\x01 C \x02 注：…       C=注释
\x01 F \x02 说出        F=内置函数
\x01 P \x02 (           P=标点
```

C 层按标记切段套色。好处：改高亮规则不用重编 dylib、重打包、重签名。

## 踩过的坑（都修了）

| 现象 | 根因 | 修法 |
|---|---|---|
| 按钮点了没反应 | `文字.截(事件,3)` 取的是「前 3 个字符」而不是「从第 3 个开始」，事件解析全错 | 新增 `文字.从`，7 处误用已改 |
| 按钮飘到分区外 | 用 `subviews.count` 当序号，把文本视图也算进去，且从下往上累加 | 只数按钮，从顶部往下排 |
| 模块叠加错乱 | `界面_文本_t` 每次新建 NSTextView 叠上去 | 原地更新内容 |
| 状态栏叠多层 | 每次新建 NSView，靠「高度和 y」猜旧状态栏 | 全局持有，只更新文字 |
| 窗口 2 秒后消失 | `NSWindow` 默认 `releasedWhenClosed=YES`，关闭时自我释放，`g_win` 成野指针 | `setReleasedWhenClosed:NO` |
| 双击看不到界面 | 启动器是 shell 脚本 / 缺依赖文件 / stdout 未重定向导致 SIGPIPE | 见 `tools/app_main.c` |

## 验证方式

**不要用进程自己的日志判断窗口是否存在**。用系统窗口服务器：

```sh
clang -O2 -o /tmp/wlist tools/window_probe.m -framework Cocoa
/tmp/wlist | grep 衡语
#  ✓ 窗口存在: owner=衡语 IDE  1268x741  层级=0
```

`owner` 字段是关键：`hengvm`（裸二进制）vs `衡语 IDE`（从 .app 启动，有应用身份）。

按钮测试不依赖鼠标（`CGEventPost` 需要辅助功能权限）：

```hl
界面.界面_触发_t("运行代码")    注：走真实 target/action 链路
```

控件坐标核对：`界面_控件清单_t` 输出每个按钮在窗口内的实际位置，
用来确认按钮没有画到分区外面。
