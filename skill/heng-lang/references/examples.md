# 衡语真实代码示例

以下代码全部来自 300 个验证项目，可直接运行。

## 聚合与统计

```
定义 记录 渠道日:
  字段 渠道 : 文本
  字段 消耗 : 数
  字段 线索 : 数
结束

开始:
  变量 数据 : 序列 渠道日 = [渠道日("抖音", 32000, 1200), 渠道日("快手", 18000, 800)]
  变量 渠道表 : 映射 文本 数 = {}
  每个 数据 为 r:
    如果 字典.有键(渠道表, r.渠道):
      将 渠道表[r.渠道] + r.消耗 放到 渠道表[r.渠道]
    否则:
      将 r.消耗 放到 渠道表[r.渠道]
    结束
  结束
  每个 字典.键(渠道表) 为 k:
    说出 k + " 消耗 " + 化成文(渠道表[k])
  结束
结束
```

## 高阶函数与闭包

```
开始:
  变量 倍 : 数 = 3
  说出 表.映射([1, 2, 3], 做法(x : 数) -> 数 => x * 倍)
  说出 表.过滤([1, 2, 3, 4, 5], 做法(x : 数) -> 真假 => x > 2)
  说出 表.折叠([1, 2, 3], 做法(累 : 数, x : 数) -> 数 => 累 + x, 0)
结束
```

## 文件读写

```
开始:
  授权 文件.读取, 文件.写入

  文件.写入(目录 + "/out.txt", "内容")

  说出 文字.长度(内容)
结束
```

## 命令行参数与分支

```
定义 做法 分发(命令 : 文本) -> 文本:
  如果 命令 = "list":
    返回 "列出"
  结束
  如果 命令 = "add":
    返回 "新增"
  结束
  返回 "未知命令"
结束

开始:
  授权 系统.参数
  变量 参 : 序列 文本 = 系统.参数()
  如果 表.长度(参) > 0:
    说出 分发(参[0])
  否则:
    说出 "用法：list | add"
  结束
结束
```

## 记录与字段赋值

```

结束
```
