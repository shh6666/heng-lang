# 衡语编程

衡语是一门中文编程语言，语法接近中文表达。文件后缀 `.hng`。

## 安装与运行

```sh
henger app.hng              # 编译并运行
henger --check app.hng      # 只检查（返回结构化诊断）
henger --check app.hng --json
henger --build app.hng -o app.hbc
henger --run app.hbc
henger --list-builtins      # 列出全部标准库与能力
henger --explain E01        # 解释错误码
```

## 语法骨架

```
注：注释用「注：」
定义 记录 物料:
  字段 编号 : 文本
  字段 库存 : 数 个
结束

定义 做法 单线成本(消耗 : 数, 线索 : 数) -> 数:
  如果 线索 <= 0:
    返回 0
  结束
  返回 消耗 / 线索
结束

开始:
  变量 名单 : 序列 文本 = ["抖音", "快手"]
  变量 库 : 映射 文本 数 = {}
  将 100 放到 库["抖音"]
  说出 "共 " + 化成文(表.长度(名单)) + " 个渠道"
  每个 名单 为 c:
    说出 c
    结束
结束
```

## 必须记住的语法要点

| 想做的事 | 正确写法 |
|---|---|
| 变量声明 | `变量 x : 数 = 1` |
| 赋值 | `x = 2` 或 `将 2 放到 库["键"]` |
| 条件 | `如果 条件:` / `否则:` / `结束` |
| 循环 n 次 | `循环 i < n:` … `i = i + 1` … `结束` |
| 遍历 | `每个 列表 为 x:` … `结束` |
| 函数 | `定义 做法 名(a : 数) -> 数:` … `返回 v` … `结束` |
| 记录 | `记录 名(...)`，字段访问 `r.字段` |
| 字段赋值 | `将 v 放到 r.字段` |
| λ 表达式 | `做法(x : 数) -> 数 => x * 2` |
| 输出 | `说出 值` |
| 类型转换 | `化成文(数)` / `化为数(文本)` |
| 量纲 | `数 元`、`数 个`、`100<元>`、`10个 × 100元/个 = 1000元` |

## 硬性限制（写代码前务必确认）

1. **`开始:` 块里不能用 `返回`** —— 用条件分支代替提前退出。
2. **顶层只能有** `导入` / `定义` / `常量` / `记录` / `开始`，**不能有顶层变量**。
   需要全局状态时用：`常量 状态 : 映射 文本 文本 = {}`。
3. **标识符不能以关键字开头**（重要）：
   - `数`、`文本` 可作变量名（已放宽）
   - 但 `结束`、`执行`、`接收`、`时间`、`输出`、`次数` 仍是关键字
   - **标识符的首字不能是这些词**。例如 `定义 做法 结束进程(...)` 会报
     「期望 做法名（遇到 KW_END 结束）」——因为「结束进程」以「结束」开头
   - 修法：换个说法，`结束进程` → `销毁进程`，`执行一步` → `推进一步`
4. **表达式可以跨行，但只能在括号内换行**：
   ```
   变量 总 : 数 = (甲 + 乙
     + 丙)
   ```
   括号外换行会被当作语句结束。
5. **能力必须先授权**：
   ```
   开始:
     授权 文件.读取, 文件.写入
     ...
   结束
   ```
6. **字符串内不能直接换行**，用 `文字.由码点(10)` 拼。

`--list-builtins` 能看完整清单。

## 标准工作流

1. `heng_check`（或 `henger --check app.hng --json`）确认语法与类型
2. 有错就按 `diagnostics[].line/column/help` 修
3. `heng_run` 看输出
4. 需要参考语法时用 `heng_examples`

## 典型错误与修法

| 错误码 | 含义 | 修法 |
|---|---|---|
| E01 | 类型/量纲不匹配 | 检查两侧类型；无量纲与带单位比较要注意 |
| E02 | 语法错误 | 常见是括号外换行、缺 `结束` |
| E03 | 下标越界 | 检查上界，下标从 0 开始 |
| E05 | 未定义变量/函数 | 检查拼写；标准库要写 `模块.函数` |
| W01 | 变量未使用 | 删掉或加 `_` 前缀 |
